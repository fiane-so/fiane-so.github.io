# Portfolio — Sofiane Woessou

Site personnel publié sur https://fiane-so.github.io

- `index.html` : la page entière (HTML/CSS/JS, aucune étape de build)
- `assets/` : portrait, favicon et CV téléchargeable
- `.github/workflows/pages.yml` : déploiement automatique sur GitHub Pages à chaque push sur `main`

Fonctionnalités : bilingue FR/EN, thème sombre/clair, palette de commandes (Ctrl/⌘ + K ou `/`),
fenêtre de code animée, compteurs, horloge de Niamey en direct, filtres de projets.

Pour mettre à jour : modifier `index.html`, commit, push. Le site se redéploie tout seul.
